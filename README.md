## Reproduce the runtime

The supported platform is Linux x86-64, CPython 3.12, in this exact public image:

`public.ecr.aws/lambda/python@sha256:a8bca562ea2ad545fbf16a97c6746671526809a23456d86ca070245524f6a472`

Its `/var/lang` AWS SDK closure is pinned in SDK_CLOSURE.json. Arbitrary host Python, `pip install` or a moving Lambda managed runtime is not equivalent. Image download is separate from the public dependency archives; no credentials are needed to download them. Storage/runtime costs remain your responsibility.

1. Inspect ARTIFACTS.json, ASSEMBLY_MAP.json and the tools. With Python 3.12, `python tools/fetch_artifacts.py --cache /absolute/cache` only checks files. Add `--execute-download` to explicitly download the exact HTTPS artifacts into that cache. This fetcher never installs or executes them. A failed partial is retained; inspect it instead of blindly retrying.
2. In the pinned Linux environment, run `python -I -B tools/assemble_runtime.py --source /absolute/repository --cache /absolute/cache --output /absolute/new-runtime`. Output must be a separate new directory, outside source/cache. Assembly performs no network, app imports or installation and refuses overwrites. It verifies exact hashes, members and POSIX modes before/readback.
3. The assembled directory deliberately excludes repository docs/tools. Runtime integrity checks reject extra files and missing dependency bytes. Keep generated bytecode out (`PYTHONDONTWRITEBYTECODE=1`).

No provider key is required for assembly or the disconnected 503 export. A real host must explicitly supply its exact origin, signing secret, durable quota/replay history, provider transport and account/allowance contract. The code refuses missing control history. Configuration/digests are not authorization. The application is not live merely because a key exists.

For local UI inspection only, serve this checkout with a trusted static web server; API operations remain unavailable. Do not present this as the required public working demo. Keep provider credentials in a server-only store, never public source, frontend, logs or command arguments.
